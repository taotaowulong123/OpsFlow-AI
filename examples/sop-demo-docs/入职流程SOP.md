# 入职流程标准操作流程 (SOP)

## 1. 入职前准备

### 1.1 HR 准备事项
- 发送入职通知邮件（入职日期、地点、所需材料）
- 准备劳动合同
- 准备工位和办公设备
- 通知相关部门

### 1.2 新员工需提交材料
- 身份证复印件
- 学历证书复印件
- 离职证明
- 银行卡信息
- 一寸照片 2 张

## 2. IT 系统开通

### 2.1 账号开通清单
| 系统 | 负责人 | 时效 | 审批级别 |
|-----|-------|------|---------|
| 企业邮箱 | IT部 | 入职前1天 | 自动 |
| OA系统 | IT部 | 入职前1天 | 自动 |
| 代码仓库 | 技术主管 | 入职当天 | 主管审批 |
| 生产环境 | 安全部 | 入职后1周 | 总监审批 |
| VPN | IT部 | 入职当天 | 主管审批 |

### 2.2 设备配置
- 笔记本电脑（按岗位标准配置）
- 显示器
- 键鼠套装
- 工牌

### 2.3 IT 开通申请表字段
- 员工姓名
- 工号
- 部门
- 岗位
- 直属主管
- 需开通系统列表
- 特殊权限说明
- 申请人签字
- 主管审批签字

## 3. 入职当天流程

1. 前台签到
2. HR 办理入职手续
3. 签署劳动合同
4. 领取办公设备
5. IT 系统账号激活
6. 部门负责人介绍团队
7. 安排导师/伙伴
8. 入职培训安排

## 4. 试用期管理

### 4.1 试用期时长
- 合同期 1-3 年：试用期 1-3 个月
- 合同期 3 年以上：试用期不超过 6 个月

### 4.2 考核节点
- 第 1 周：适应情况反馈
- 第 1 月：阶段性目标考核
- 试用期满前 2 周：转正评估
