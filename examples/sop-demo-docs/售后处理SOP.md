# 售后处理标准操作流程 (SOP)

## 1. 退款处理流程

### 1.1 退款申请受理
- 客户提交退款申请后，系统自动创建工单
- 工单状态标记为"待处理"
- 自动分配给对应品类的售后专员

### 1.2 退款原因分类
| 原因代码 | 原因描述 | 处理时效 | 审批级别 |
|---------|---------|---------|---------|
| R001 | 商品质量问题 | 24小时 | 自动审批 |
| R002 | 商品与描述不符 | 24小时 | 自动审批 |
| R003 | 物流损坏 | 48小时 | 主管审批 |
| R004 | 客户主观不满意 | 72小时 | 主管审批 |
| R005 | 重复下单/误操作 | 24小时 | 自动审批 |

### 1.3 处理规则
1. 订单金额 ≤ 100元：自动退款，无需审批
2. 订单金额 100-500元：需售后专员确认
3. 订单金额 > 500元：需主管审批
4. 同一客户30天内退款次数 ≥ 3次：标记为高风险，需主管审批

### 1.4 退款执行
- 原路退回至支付账户
- 退款完成后自动发送通知
- 更新库存状态

## 2. 换货处理流程

### 2.1 换货条件
- 商品签收后7天内
- 商品未使用、未损坏
- 包装完整，附件齐全

### 2.2 换货流程
1. 客户申请换货
2. 审核换货条件
3. 生成退回物流单
4. 客户寄回商品
5. 仓库验收
6. 发出新商品
7. 更新工单状态

## 3. 投诉处理流程

### 3.1 投诉分级
- P0（紧急）：涉及安全问题，2小时内响应
- P1（高优）：批量质量问题，4小时内响应
- P2（普通）：个别商品问题，24小时内响应
- P3（低优）：建议类反馈，72小时内响应

### 3.2 处理步骤
1. 记录投诉详情
2. 分级分类
3. 指派处理人
4. 调查核实
5. 制定解决方案
6. 执行方案
7. 客户确认
8. 关闭工单

## 4. 异常商品处理

### 4.1 退款率异常判定标准
- 单商品7日退款率 > 5%：预警
- 单商品7日退款率 > 10%：需立即处理
- 单商品30日退款率 > 8%：建议下架审查

### 4.2 处理措施
1. 暂停商品推广
2. 联系供应商核实
3. 抽检库存商品
4. 根据结果决定：继续销售 / 整改 / 下架
5. 生成处理报告
