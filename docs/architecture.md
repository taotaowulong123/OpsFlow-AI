## LangGraph 状态机

```
         START
           │
           ▼
      ┌─────────┐
      │ Planner │  分析任务，生成执行计划
      └────┬────┘
           ▼
      ┌──────────┐
      │Retriever │  检索知识库，获取相关文档
      └────┬─────┘
           ▼
      ┌──────────┐
      │ Executor │  调用工具执行任务步骤
      └────┬─────┘
           ▼
      ┌──────────┐
      │ Reviewer │  检查结果完整性
      └────┬─────┘
           │
     ┌─────┴─────┐
     │needs_approval?│
     └─────┬─────┘
      yes/ │ \no
         ▼    ▼
   ┌──────────┐  END
   │ Approver │
   └────┬─────┘
   approved/rejected
      │      │
      ▼      ▼
   Executor  END(failed)
```

## 数据流

1. 用户输入任务 → 创建 Task 记录
2. 触发执行 → 创建 TaskRun
3. 每个节点执行 → 创建 RunStep + 实时 SSE 推送
4. 工具调用 → 创建 ToolInvocation
5. 需要审批 → 创建 Approval，暂停执行
6. 审批通过 → 恢复执行
7. 完成 → 更新 Task/TaskRun 状态
